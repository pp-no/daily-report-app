## 作業概要

Spring Bootバックエンドの開発環境を構築し、DB設計・エンティティ・Repositoryの実装まで完了。Spring Boot起動とFlywayによるテーブル自動生成を確認した。

---

## 作業内容

### 1. CURRICULUM.md バージョン更新

**目的：** カリキュラムの技術スタックを2026年時点の安定版に揃える

**実施内容：**
- Java 17 → 21（LTS）
- Spring Boot 3.x → 3.4.5
- React 18 → 19
- PostgreSQL 15 → 17
- Node.js 18以上 → 22 LTS
- Dockerfileベースイメージを `jdk17` → `jdk21`、`node:18-alpine` → `node:22-alpine` に更新

**成果物：**
- `CURRICULUM.md`（バージョン更新）

---

### 2. Spring Boot プロジェクト生成・設定

**目的：** バックエンドのプロジェクト雛形を作成しIntelliJで動作させる

**実施内容：**
- Spring Initializr（start.spring.io）でプロジェクト生成
  - Gradle / Java 21 / Spring Boot 3.5.x
  - Dependencies: Web, JPA, Security, Mail, PostgreSQL, Lombok, Validation, DevTools, Flyway
- `backend/` をプロジェクトルートに配置
- build.gradleのバージョンを `3.5.15-SNAPSHOT` → `3.4.5`（安定版）に修正
- Snapshotリポジトリを削除
- IntelliJ で Gradle 同期実行
- JDK互換性エラー（Java 26 は Gradle 8.14.4 未対応）を解決
  - IntelliJ 経由で Eclipse Temurin JDK 21 をインストール
  - Gradle JVM を JDK 21 に変更

**成果物：**
- `backend/build.gradle`（バージョン修正）
- `backend/src/main/resources/application.properties`

---

### 3. Docker Compose で PostgreSQL 起動

**目的：** ローカル開発用DBを立ち上げる

**実施内容：**
- `docker-compose.yml` を作成（postgres:17、ポート5432、ボリューム設定）
- `docker compose up -d` で起動
- `docker exec` で `dailyreport` データベースへの接続を確認

**成果物：**
- `docker-compose.yml`

---

### 4. DB設計・エンティティ・Repository実装（Phase 3）

**目的：** アプリの中核となるデータモデルを定義し、DBと接続できる状態にする

**実施内容：**
- Flyway マイグレーションSQLを作成
  - `V1__create_users.sql`：usersテーブル定義
  - `V2__create_daily_reports.sql`：daily_reportsテーブル定義
- JPA エンティティクラスを作成
  - `User.java`：`@OneToMany` でDailyReportと関連付け
  - `DailyReport.java`：`@ManyToOne` でUserと関連付け
- Spring Data JPA Repository を作成
  - `UserRepository.java`：メール検索・通知対象ユーザー検索
  - `DailyReportRepository.java`：日付検索・通知対象日報検索（`@Query`）
- Spring Boot 起動 → Flyway が自動でテーブル作成・起動確認

**成果物：**
- `backend/src/main/resources/db/migration/V1__create_users.sql`
- `backend/src/main/resources/db/migration/V2__create_daily_reports.sql`
- `backend/src/main/java/com/dailyreport/backend/domain/entity/User.java`
- `backend/src/main/java/com/dailyreport/backend/domain/entity/DailyReport.java`
- `backend/src/main/java/com/dailyreport/backend/domain/repository/UserRepository.java`
- `backend/src/main/java/com/dailyreport/backend/domain/repository/DailyReportRepository.java`
