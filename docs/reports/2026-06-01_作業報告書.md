### 2. Docker化（Phase 9）

**目的：** バックエンド・フロントエンド・DBを `docker compose up` の1コマンドで起動できるようにする

**実施内容：**

#### `backend/Dockerfile`（マルチステージビルド）

| ステージ | ベースイメージ | 処理 |
|---|---|---|
| ビルドステージ | `eclipse-temurin:21-jdk-alpine` | `./gradlew bootJar -x test` でJAR生成 |
| 実行ステージ | `eclipse-temurin:21-jre-alpine` | JARのみコピーして `java -jar app.jar` |

- ビルド設定ファイル（`gradlew` / `build.gradle`）を先にコピーして依存ライブラリのダウンロードをキャッシュ層に分離
- `-x test` でDB接続が必要なテストをスキップ

#### `frontend/Dockerfile`（マルチステージビルド）

| ステージ | ベースイメージ | 処理 |
|---|---|---|
| ビルドステージ | `node:22-alpine` | `npm run build` で静的ファイル（`dist/`）を生成 |
| 配信ステージ | `nginx:alpine` | `dist/` のみコピーして静的ファイルを配信 |

- `VITE_API_URL=""` にすることでaxiosが相対URL（`/api/...`）を使用
- `package.json` / `package-lock.json` を先にコピーして `npm ci` をキャッシュ層に分離

#### `frontend/nginx.conf`

- `/api/*` へのリクエストを `http://backend:8080` にプロキシ転送
- `try_files $uri $uri/ /index.html` でReact RouterのSPAルーティングに対応

#### `docker-compose.yml`（3サービス構成に更新）

| サービス | 内容 |
|---|---|
| `db` | PostgreSQL 17。`healthcheck` で起動完了を確認 |
| `backend` | `db` が healthy になってから起動。環境変数で `SPRING_DATASOURCE_URL` を `db:5432` に上書き |
| `frontend` | ポート80を公開。nginx が `/api/*` をbackendにプロキシ |

#### `.env.example`

- Docker Compose 用シークレット（DB/JWT/Mail）のテンプレートを作成
- `.gitignore` にルートの `.env` を追加

**成果物：**

- `frontend/nginx.conf`（新規）
