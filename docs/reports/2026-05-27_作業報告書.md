## 作業内容

### 1. Pencil MCP接続設定

**目的：** Claude CodeからPencilデザインツールをMCP経由で操作できる環境を構築する。

**実施内容：**
- プロジェクトルートに `.mcp.json` を新規作成
- Pencil VS Code拡張機能（`highagency.pencildev-0.6.50`）のMCPサーバーバイナリを特定
- 正しい接続引数（`--app visual_studio_code --agent claudeCodeCLI`）を調査・設定

**成果物：**
- `/daily-report-app/.mcp.json`

**設定内容：**
```json
{
  "mcpServers": {
    "pencil": {
      "command": "~/.pencil/mcp/visual_studio_code/out/mcp-server-darwin-arm64",
      "args": ["--app", "visual_studio_code", "--agent", "claudeCodeCLI"],
      "type": "stdio"
    }
  }
}
```

### 2. UI/UXデザイン作成（Pencil）

**目的：** CURRICULUM.md Phase 7に基づき、フロントエンド実装前に全画面のデザインを確定する。

**対象ファイル：** `pencil-new.pen`

**デザインシステム：**
- プライマリーカラー：`#3B82F6`（ブルー）
- 背景：`#F1F5F9`（ライトグレー）
- サーフェス：`#FFFFFF`（ホワイト）
- テキスト（主）：`#0F172A`
- テキスト（副）：`#64748B`
- サイドバー：`#1E293B`（ダークネイビー）

**作成画面一覧（全7画面）：**

| # | 画面名 | パス | 主な要素 |
|---|---|---|---|
| 1 | ログイン | `/login` | メール・パスワード入力、ログインボタン、登録リンク |
| 2 | ユーザー登録 | `/register` | 名前・メール・パスワード・業務開始時刻 |
| 3 | 日報一覧 | `/reports` | 日報カードリスト、公開/非公開バッジ、新規作成ボタン |
| 4 | 日報作成 | `/reports/new` | 3セクション入力フォーム、まとめ欄、公開設定トグル |
| 5 | 日報編集 | `/reports/:id/edit` | データ入力済みフォーム、更新・キャンセルボタン |
| 6 | 公開日報一覧 | `/public` | 3カラムカードグリッド、著者情報、キーワード検索 |
| 7 | プロフィール設定 | `/settings` | プロフィール編集、パスワード変更、通知設定、ログアウト |

**共通コンポーネント：**
- サイドバー（Reusable Component）：ロゴ、ナビゲーション4項目、ユーザー情報
