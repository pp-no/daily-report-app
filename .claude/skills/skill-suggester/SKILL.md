# Skill Suggester スキル

`.claude/prompt-log.md` に蓄積されたプロンプトを分析し、スキル化の候補を提案する。

## 手順

### 1. ログファイルを読む

```bash
cat .claude/prompt-log.md
```

ログが存在しない・空の場合は「まだプロンプトが蓄積されていません」と伝えて終了する。

### 2. 既存スキルを確認する

```bash
ls .claude/skills/
```

各スキルの `SKILL.md` を読み、すでにカバーされている操作を把握する。重複提案を避けるため。

### 3. プロンプトをカテゴリ別に分類する

以下のカテゴリを目安に、各プロンプトをグループ化する（複数カテゴリに重なる場合は主目的で判定）：

| カテゴリ | 例 |
|---|---|
| git操作 | コミット、プッシュ、ブランチ操作 |
| 実装依頼 | 機能追加、バグ修正、リファクタリング |
| デバッグ調査 | エラー確認、ログ調査、原因特定 |
| ドキュメント | コメント追加、報告書、README |
| 環境・設定 | Docker、設定ファイル、ツール導入 |
| コードレビュー | レビュー依頼、品質チェック、lint |
| Issue管理 | Issue作成、クローズ、GitHub操作 |
| その他 | 上記に当てはまらないもの |

### 4. スキル化の判断

各カテゴリについて以下を評価する：

**スキル化を提案する条件（すべて満たすこと）**
- そのカテゴリに **20件以上** の記録がある
- 既存スキルでカバーされていない
- 手順が3ステップ以上あり、毎回考える必要がある

**スキル化しない（提案しない）**
- 20件未満のカテゴリ
- 既存スキルで十分対応できるもの
- 「はい」「わかりました」などの返答に近いもの

### 5. 提案レポートを出力する

```
## プロンプトログ分析レポート

### カテゴリ別集計
| カテゴリ | 件数 | スキル化 |
|---|---|---|
| git操作 | 32件 | ✅ 既存スキルあり |
| 実装依頼 | 25件 | 🆕 候補 |
| デバッグ調査 | 8件 | ⏳ 蓄積中 |
...

---

### スキル化候補

#### 候補1: [スキル名]
**トリガー例**: 「〇〇して」「△△を確認して」
**件数**: N件
**概要**: このスキルが自動化する内容（1〜2文）
**スキル化の理由**: 頻度・複雑さ・現状の手間

---

## まだスキル化不要なカテゴリ
- 〇〇（N件）: あと△件で候補になります
```

候補が0件の場合は「まだスキル化できるパターンが蓄積されていません（最多カテゴリ: 〇〇 N件）」と伝える。

### 6. ユーザーに確認する

「上記の候補をスキルとして作成しますか？」と確認し、承認されたら `.claude/skills/<name>/SKILL.md` を作成する。

作成後、`prompt-log.md` の該当エントリをスキル化済みとしてマーク（先頭に `~~` で打ち消し線）する。

## 注意事項

- 提案は最大3件に絞る（多すぎると価値が薄れる）
- ログの内容はプライバシー配慮のため外部に送らない
- スキル作成後も元のログは残す（削除しない）
